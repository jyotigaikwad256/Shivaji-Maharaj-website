🚩 Chhatrapati Shivaji Maharaj Tribute Portal
A responsive, interactive informational portal dedicated to the life, legacy, and administration of Chhatrapati Shivaji Maharaj. This project serves as a digital tribute, utilizing modern web technologies to provide an engaging educational experience. 
🚀 Live Demo
View Live Project
✨ Key Features
Interactive Historical Timeline: A dynamic timeline built with JavaScript to explore key life events and battles.
Forts Gallery: A responsive CSS Grid-based gallery showcasing the architectural marvels of the Maratha Empire.
Responsive Design: Fully optimized for mobile, tablet, and desktop viewing using CSS Flexbox and Media Queries.
Smooth Navigation: Implemented smooth-scroll behavior and a sticky navigation bar for better user experience.
Semantic HTML: Structured with SEO best practices and web accessibility in mind.
🛠️ Tech Stack
HTML5: For structured and semantic content.
CSS3: Including Flexbox, Grid, and custom animations.
JavaScript (ES6+): For DOM manipulation and interactivity.
FontAwesome: For high-quality iconography.
Google Fonts: Utilized for traditional and readable typography.
